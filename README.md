# E-Commerce Database Management System Using Qdrant Vector Database

A functional, lightweight mini-project demonstrating a **Hybrid Relational-Vector Database Architecture** for high-precision semantic product discovery, built for college database technology assessments.

---

## 1. System Overview

This application bridges traditional relational transaction management with modern artificial intelligence vector search:

* **Primary Database (SQLite 3)**: Serves as the authoritative source of truth for products, categories, pricing, stock inventory, and customer orders with full ACID compliance.
* **Specialized Vector Database (Qdrant)**: Stores 384-dimensional dense vector embeddings generated by `sentence-transformers/all-MiniLM-L6-v2` to enable semantic similarity search using Cosine distance.
* **Backend (Python / Flask)**: Provides RESTful endpoints and coordinates synchronous dual-writes (SQLite first, followed by Qdrant vector indexing).
* **Frontend (HTML5 / Vanilla CSS / JavaScript)**: A clean, responsive single-page catalogue featuring dual-mode search tabs (Semantic AI vs Keyword), sample query chips, real-time similarity badges, and an architecture diagnostic drawer.

## 3. Quickstart: Running Locally

### Step 1: Install Dependencies
Open a terminal in the project directory and install the required Python packages:
```bash
pip install -r requirements.txt
```

### Step 2: Start Qdrant Vector Database (Docker)
Start the local Qdrant container:
```bash
docker compose up -d
```
*Web Dashboard: Open [http://localhost:6333/dashboard](http://localhost:6333/dashboard) to view Qdrant collections.*

### Step 3: Seed Relational Database & Vector Index
Initialize the SQLite schema, populate 35 sample products, and index dense vectors into Qdrant:
```bash
python seed.py
```

### Step 4: Launch the Web Application
Start the Flask development server:
```bash
python app.py
```
Open your browser and navigate to:
**[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 4. Laboratory Demonstration Guide (5 Minutes)

### Part A: Interactive Web UI Demonstration
1. **Homepage & Diagnostics**:
   * Open `http://127.0.0.1:5000`.
   * Note the green badge: `Qdrant Online (35 vectors)`.
   * Click **"System Info"** to display the dual-database architecture drawer.
2. **Semantic AI Search**:
   * Click the sample chip: `🎧 Affordable headphones for travelling`.
   * Observe how the application retrieves *Active Wireless Noise-Cancelling Headphones* as the top result with a **Similarity Match Badge (e.g. 52.9% Match)**.
   * Try other natural-language queries:
     * `"Books suitable for learning programming."`
     * `"Comfortable shoes for running."`
3. **Category-Filtered Semantic Search**:
   * Select `Clothing` in the category filter dropdown and search `"gear for marathon jogging"`.
   * Observe that results are strictly filtered to the Clothing category while maintaining semantic ranking.
4. **Keyword Search (SQLite LIKE)**:
   * Switch tabs to **"Keyword Search (SQLite LIKE)"** and search for `"laptop"`.
   * Observe exact lexical matching without similarity scoring.
5. **Product CRUD & Real-time Dual-Write**:
   * Click **"Add Product"**, enter a test item, and click **Save**.
   * The item is inserted into SQLite and immediately vectorized into Qdrant.
   * Edit or delete the item to demonstrate synchronized updates.

## 5. Architectural Comparison: SQLite vs Qdrant

| Dimension | SQLite 3 (Relational Database) | Qdrant (Vector Database) |
| :--- | :--- | :--- |
| **Primary Data Model** | Relational tables (Rows and Columns) | Dense vector embeddings + JSON payload |
| **Indexing Mechanism** | B-Tree / B+Tree | HNSW (Hierarchical Navigable Small World) |
| **Search Paradigm** | Exact match, range queries, SQL LIKE substring | Approximate Nearest Neighbor (ANN) search |
| **Distance Metric** | Scalar comparisons (`=`, `<`, `>`, `BETWEEN`) | Cosine distance, Dot product, Euclidean distance |
| **ACID Compliance** | Full ACID guarantees with WAL | Eventual consistency across vector shards |
| **Vector Support** | Supported via extensions (e.g. `sqlite-vss`) | Native, hardware-accelerated vector search |
| **Role in System** | Authoritative Source of Truth (orders, stock, prices) | Accelerated semantic product retrieval index |
